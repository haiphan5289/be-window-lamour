## Business Rules

| Rule | Description |
|------|-------------|
| Số chứng từ | Prefix `BTL`, format `BTL{5 digits}` — sinh tại WPF client qua `next-code` |
| Ít nhất 1 dòng | `CreateSalesReturnUseCase` throw `DomainException` nếu `Lines.Count == 0` |
| Sản phẩm còn kinh doanh | Chỉ cho phép `Product.IsActive == true`, ngược lại 400 |
| Kho hợp lệ | Mỗi dòng phải có `warehouse_id` trỏ tới 1 `Warehouse` tồn tại (tránh FK violation 500) |
| Chiết khấu | `DiscountRate` clamp `Math.Max(0, Math.Min(100, rate))` trước khi tính `DiscountAmount` |
| Thuế/giá vốn | BE tự tính `TaxRate`/`CostPrice` từ `Product` tại thời điểm ghi sổ — bỏ qua giá trị client gửi lên |
| Trạng thái | `Confirmed` (đã ghi sổ, cộng kho) ⇄ `Held`/`Draft` (chưa ghi sổ — 2 giá trị lịch sử tương đương nhau, xem `SalesReturnStatus`) |
| Tạo mới ("Cất") | Luôn kết thúc `Confirmed`, `ConfirmedAt = UtcNow`, cộng tồn kho ngay trong `CreateSalesReturnUseCase` |
| Ghi sổ (`Confirm`) | Cộng `StockQuantity` mỗi dòng — chặn nếu đã `Confirmed` |
| Bỏ ghi (`Unconfirm`) | Trừ lại `StockQuantity` (kiểm tra đủ tồn trước) — chỉ cho phép từ `Confirmed` |
| Sửa/Xóa | Không chặn theo trạng thái ở BE — luôn hoàn tác tồn kho dòng cũ nếu đang `Confirmed` trước khi thao tác |
| Denormalize | `ProductCode`/`ProductName` copy vào dòng tại thời điểm tạo, không đổi khi Product đổi sau đó |
| Tài khoản mặc định | `ReturnAccount="5212"`, `DebtAccount="131"`, `DiscountAccount="5211"`, `TaxAccount="33311"`, `CostAccount="1561"`, `CogsAccount="632"` |
| `return_type` | `0 = ReduceDebt` (Giảm trừ công nợ), `1 = CashRefund` (Trả lại tiền mặt) |
| DB Transaction | Create/Update/Delete/Confirm/Unconfirm đều dùng `IUnitOfWork.BeginAsync` → `CommitAsync`/`RollbackAsync` |
| Ngày lưu trữ | `AccountingDate`/`DocumentDate` ép `DateTimeKind.Utc` trước khi lưu |

## Edge Cases & Error Handling

| Scenario | Expected Behavior | Handled? |
|----------|------------------|----------|
| Create with 0 lines | 400 `DomainException("At least one line item is required.")` | ✅ |
| Product not found / inactive | 400 with product name in message | ✅ |
| Warehouse not selected / invalid | 400 `"Vui lòng chọn Kho cho hàng hóa '...'."` (prevents raw FK 500) | ✅ |
| Confirm an already-Confirmed return | 400 `"Chứng từ đã ở trạng thái đã ghi sổ rồi."` | ✅ |
| Unconfirm a non-Confirmed return | 400 `"Chứng từ chưa ở trạng thái đã ghi sổ, không thể bỏ ghi."` | ✅ |
| Unconfirm when stock insufficient (already re-sold) | 400, blocks the stock deduction | ✅ |
| Delete/Update while Confirmed | Auto-reverses stock first, then proceeds — not blocked by status | ✅ |
| Discount rate outside 0–100 | Clamped server-side, never rejected | ✅ |
| `[Authorize]` | Currently disabled — any caller can reach these endpoints | ⚠️ Known gap, intentional per TODO |
